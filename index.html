Prospector

Prospector is a private tool run by Fellipe Gonçalves Leite, an independent web developer based in Brazil. It runs on his own computer and helps him send a small number of plain-text emails to local businesses about website work, from his own Gmail account, and notice when someone replies. It is not offered to other users.

Privacy policy

Gmail access. Prospector asks for access to one Gmail account only: the owner's own. It uses that access to create drafts, send emails the owner has approved to be sent, and read replies to those emails. It does not read, store or use any other Gmail account.

What is stored. Business names, public business email addresses and public website facts, the emails sent, and the replies received are stored in a local database on the owner's computer. Nothing is uploaded to a server run by Prospector, because there is none.

Processing by AI providers. To write emails and to sort replies (for example, interested or not interested), public business information and reply text are sent to the AI command-line tools the owner already uses (OpenAI Codex or Anthropic Claude Code) under their own terms.

Sharing. Data is never sold, rented or shared for advertising. Gmail data is used only to provide the functions above, in line with the Google API Services User Data Policy, including its Limited Use requirements.

Opting out and deletion. Anyone who replies "no" or asks to stop is never emailed again. To ask for your information to be deleted, email the address below.
